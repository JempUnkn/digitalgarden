config editor

This is a static site — there's no server to save to. Edit the fields below, hit generate config.js, then download it and overwrite js/config.js in the project. That's the whole deploy step.

// identity
// about / whois
// ~/dir — projects
// ~/blog — posts
// playlist

The id is the part of the Spotify track URL right after /track/ and before the ?si=. Playback happens inside Spotify's own embedded player, so this project never touches the actual audio file.

Copy this into js/config.js (or download it straight to that path) and reload the site to see the changes.
